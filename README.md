# Matrix–WeChat

[English](README.md) | [简体中文](README.zh-CN.md)

A Matrix–WeChat bridge using the WeChat Linux client. It bridges the currently logged-in WeChat account to private Matrix rooms for one configured Matrix user.

## Documentation

- [Bridge setup](docs/setup.md) — install with Docker Compose and register with your homeserver.
- [Usage](docs/usage.md) — log in, manage chats, and use bridge commands.
- [Features and limitations](docs/features.md) — supported messages and bridge behavior.
- [Development](docs/development.md) — build, test, and work on the bridge.

Setup requires an amd64 Linux host and access to register an application service on your Matrix homeserver. Encrypted Matrix rooms are not supported.
