# 使用指南

[English](usage.md) | [简体中文](usage.zh-CN.md)

请先完成[部署指南](setup.zh-CN.md)。桥接仅服务 `bridge.owner`，并跟随当前登录的微信账号。

## 登录

接受管理房间邀请，发送 `login qr`，使用手机微信扫描图片并确认桌面端登录。每次命令发送一张二维码；需要时可再次请求。

如果桌面客户端记住了账号，发送 `login prompt` 请求手机确认。直接发送 `login` 作用相同。启用网页界面时，也可通过 <http://127.0.0.1:18742/> 登录。Compose 禁用了自动登录请求，因此需要手动发起登录。

登录后，桥接会为可见的微信会话创建私有 Matrix 房间，这些房间称为会话桥接房间（portal）。桥接邀请你加入，并按时间从早到晚导入全部本地缓存历史。导入可能需要一些时间，重启后可继续。启用[双向身份映射](setup.zh-CN.md#双向身份映射double-puppeting)后，桥接会自动接受其房间的待处理邀请。

## 命令

只有 `bridge.owner` 可以执行命令。在管理房间中直接发送；在会话桥接房间中需加上 `!wechat` 前缀（或配置的 `bridge.command_prefix`），例如 `!wechat status`。

| 命令 | 用途 |
| --- | --- |
| `help` | 列出可用命令。 |
| `status` | 查看当前运行时状态。 |
| `capabilities` | 查看支持和不支持的操作。 |
| `login qr` | 请求登录二维码。 |
| `login prompt` | 为已记住的账号请求手机确认。 |
| `logout` | 结束原生微信会话。 |
| `list contacts` | 列出缓存的联系人及其 ID。 |
| `list groups` | 列出缓存的群及其 ID。 |
| `start-chat <ID>` | 使用缓存的联系人或会话 ID 创建或打开桥接房间。 |
| `sync` | 请求执行一次同步。 |

可通过 `list contacts` 或 `list groups` 查找 `start-chat` 所需的 ID。离开 Matrix 桥接房间不会退出微信群。

## 发送消息

在会话桥接房间中发送的消息会发往对应的微信会话。支持文本、文本引用回复、JPEG/PNG/GIF 图片、文件和 MP4 上传。表情回应会转换为包含该表情的文本引用回复；目标消息必须已有确认的微信消息 ID。

桥接会等待微信源记录中出现带服务器 ID 的匹配消息，才确认发送成功。结果不明确或中途被打断的发送会标记为不确定，绝不自动重新提交。重试前请先在微信中检查。

接收消息和媒体处理请参阅[功能与限制](features.zh-CN.md)。

## 退出登录与连接中断

发送 `logout`，或点击网页界面的 Log out 按钮。退出过程遵循原生客户端的聊天记录设置。只有微信确认认证已结束后才报告成功；等待期间 `status` 显示 `logging_out`。在你明确请求重新登录前，自动登录保持禁用。

桥接会发送一次退出或连接中断通知，恢复登录后再发送一次恢复通知。二维码刷新和中间登录状态不会产生通知。中断期间已进入队列的消息会收到一次等待通知。

运行时不可用、已退出或切换到其他账号时，已有桥接房间仍可阅读，但禁止从 Matrix 向这些房间发送新消息。如果原生群成员列表确认当前账号已不在群内，也会禁止发送；仅列表不完整并不能证明已退群。恢复访问后会还原你原来的权限等级；管理房间始终允许发送登录命令。

## 可选 Android 登录监听器

如果安装了 Bun，并通过 ADB 连接 Android 手机，可在仓库根目录运行以下命令，批准待处理的桌面端登录请求：

```sh
bun packages/wechat-runtime/scripts/adb-login.ts --watch
```

需要启用运行时的网页界面监听端口。手机锁定时监听器会等待。连接多台设备时设置 `ANDROID_SERIAL`。去掉 `--watch` 只检查一次，按 Ctrl+C 停止监听。详情请参阅[运行时文档](../packages/wechat-runtime/README.zh-CN.md)。
