# 功能与限制

[English](features.md) | [简体中文](features.zh-CN.md)

## 历史消息与同步

登录后，桥接会为可见的微信会话创建私有 Matrix 房间，并以可恢复的分页方式，按时间从早到晚导入全部本地缓存历史。通过 tRPC 轮询标准化的历史消息，并核对近期更新与撤回。持久化的游标和映射可在任一服务重启后保留。重启桥接不会停止微信客户端或网页界面。

## 接收消息

支持接收文本、引用回复、提及、图片、表情包/GIF、缓存的 MP4 视频、解码为 WAV 的语音、文件、位置、系统通知、分享链接和微信视频号卡片。文章卡片在标题和描述旁显示小缩略图；视频号保留视频封面，仅在现有运行时能提供可播放数据时展示视频。也会同步缓存的名称、头像、群公告和成员列表。

转账和红包**仅供查看**：Matrix 显示带有可用金额、备注或祝福语以及只读标记的格式化卡片。桥接不能收款或领取红包。这些卡片可像普通消息一样被引用；系统消息不能引用。卡片使用 [Matrix 支持的 HTML](https://spec.matrix.org/v1.19/client-server-api/#mroommessage-msgtypes)，并提供纯文本后备内容和供支持的客户端使用的链接预览元数据；实际外观因 Matrix 客户端而异。

缓存媒体缺失时显示可读的占位内容，并分批轮换重试。图片仅有缓存缩略图时，显示带标记的预览。运行时完成原生下载验证后，可通过微信自身的协程队列请求缺失原图。原图通过校验和验证后，桥接会编辑已有的 Matrix 消息以补上原图，桥接重启后也可继续。明确的微信撤回会撤回对应 Matrix 事件；存储中的记录消失并不等于撤回。

## 发送消息

支持发送文本、文本引用回复、JPEG/PNG/GIF 图片、文件，以及通过现有文件上传路径发送 MP4。原生接口返回确认不代表消息已送达：桥接会等待出现带服务器 ID 的匹配源记录，并抑制其回显。结果不明确或中途被打断的发送会标记为不确定，绝不自动重新提交，包括发送过程中 API 连接失败的情况。

Matrix 表情回应会作为包含该表情的文本引用回复发送。被回应的消息必须在该会话中已有确认的微信消息 ID。

## 限制

不支持发送原生表情包、语音或位置，不支持构造原生提及、原生撤回、修改群或个人资料、在线状态、加密 Matrix 房间，以及主动下载未缓存的视频或文件。无法播放的视频号内容仍显示封面卡片。离开 Matrix 房间不会退出微信群。

桥接在启动时注册机器人，并在头像为空时自动设置内置微信头像；已有的自定义头像会保留。同步使用经过身份验证的变更日志，只唤醒受影响的会话，每分钟执行一次恢复扫描。日志缺口或运行时重启会通过已有事件映射重放缓存历史。媒体重试采用持久化退避（5 秒至 5 分钟），持续重试；经过校验的缓存文件到达通知会立即唤醒对应消息。
